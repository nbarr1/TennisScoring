# 🎾 TennisScoring

**GE Vernova Tennis League**

Welcome to TennisScoring, a full-featured league scoring platform designed for the GE Vernova Tennis League. This project balances robust functionality, real-time updates, and cross-platform compatibility to streamline tennis scoring for both players and organizers.

---

## 🌟 Features

- Live, real-time scoring and match tracking
- Player rankings and statistics
- Match workflows from scheduling to results
- Multi-platform support, including web, iOS (Swift), and Android (Kotlin)
- Wearable compatibility (Apple Watch & Wear OS)
- Modern, mobile-first UI built with TypeScript & JavaScript

---

## 🚀 Tech Stack

- **Frontend:** TypeScript, JavaScript (React/Next.js or similar frameworks)
- **Mobile:** React Native, Kotlin (Android), Swift (iOS)
- **Backend/Cloud:** Firebase, Google Cloud (assumed based on stack)
- **Other:** Monorepo structure, TurboRepo, pnpm
