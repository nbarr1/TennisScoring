# Changelog

This changelog records user-visible and operational changes for the current stable repository.

## [1.0.1] — 2026-06-10

### Current stable state

- Confirmed the repository as a stable, releasable Version 1 baseline.
- Updated documentation to match the current monorepo layout, package versions, Firebase workflows, CI gates, and setup commands.
- Removed stale planning language and outdated framework versions.

### Included product state

- Web division onboarding is available for creating a division or joining by invite code.
- Web tutorial completion routes users into division onboarding before dashboard access.
- Dashboard users without a division have a direct onboarding call to action.
- Shared scoring, ranking, profile utilities, Firebase Functions, Firebase client hooks, web routes, mobile routes, and wearable companion code are part of the stable baseline.

## [1.0.0] — Historical baseline

- Established the initial Version 1 product baseline for web, mobile, Firebase, shared scoring/ranking logic, profile utilities, messaging, feedback, and deployment documentation.
