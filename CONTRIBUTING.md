# Contributing

First off, thank you for considering contributing to this project! It's people like you that make open-source software such a great community. 

## How to Contribute

### Reporting Bugs
If you find a bug, please create an issue using the Bug Report template. Include as much detail as possible:
* Operating system and version
* Steps to reproduce the behavior
* Expected behavior vs. actual behavior
* Screenshots or logs if applicable

### Reporting Accessibility Barriers
If something is hard or impossible to use with a disability or assistive technology, use the Accessibility issue template, or choose **Accessibility** in the app's Feedback form. See [ACCESSIBILITY.md](./ACCESSIBILITY.md) for the project's goals, known limitations, and response targets.

### Suggesting Enhancements
Feature requests are always welcome. Please use the Feature Request issue template and clearly describe:
* The problem you are trying to solve
* Your proposed solution
* Any alternative solutions you've considered

### Pull Requests
1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code adheres to the existing formatting and linting rules.
6. For user interface changes, complete the accessibility checklist in the pull request template.
7. Issue that pull request!

## Development Setup
1. Clone the repository locally.
2. Install dependencies using standard package managers (e.g., `npm install`, `flutter pub get`, or `pip install -r requirements.txt` depending on the active stack).
3. Ensure you have the appropriate environment variables configured (check `.env.example`).
